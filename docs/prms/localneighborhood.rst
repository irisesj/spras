Local Neighborhood
===================
Description
------------
Local Neighborhood is a simple pathway reconstruction algorithm currently used for
helping new contributors get accustomed to implementing an algorithm into SPRAS. It
takes a network edge list and node list as an input. The nodes are used as an 
endpoint to generate the network's edges as the algorithm's output.

The output should be an edgelist that indicates connected nodes, edge weight and direction. 
For Local Neighborhood, all edges are marked as 1 (unweighted) and U (undirected).

**Parameters:** None in particular
